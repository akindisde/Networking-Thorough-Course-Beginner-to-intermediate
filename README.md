# Networking Theory/pratice Course — Beginner to Strong Intermediate

A structured path from zero networking background to CCNA/NSE4 readiness: ~65 lessons across 14 modules, every lesson following Problem → Concept → Demonstration → Wireshark Verification → Security Angle → Hands-On Lab.

## Design principles
Spiral learning (concepts revisited with more depth later), failure-first teaching, security woven into every module rather than isolated, and Gulf-relevant context (FortiGate, SD-WAN) throughout.

## Why this exists
Teaching a concept clearly enough to structure a full course around it is a stronger proof of understanding than passing a multiple-choice exam about it. This course is being built in public as I work toward CCNA and NSE4.
